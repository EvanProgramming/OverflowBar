# Using OverflowBar

Open OverflowBar from Applications. On first launch, setup guides you through permissions and icon selection. Later launches open **Menu Bar** settings.

## Choose icons

1. Grant Accessibility so OverflowBar can identify and arrange supported status items.
2. Optionally grant Screen Recording for live previews. Available application icons are used without it.
3. Open **Menu Bar** settings, select **Refresh Icons**, and use the **Hide** switches to select the icons you want to move.
4. In setup, select **Hide Icons & Finish**. In settings, turn on **Hide selected icons**.

Protected system controls are excluded. Icons OverflowBar cannot safely identify remain visible.

## Open the second row

Click **Open OverflowBar** in the menu bar to show the second row, then select an icon to open its original menu or popover. If the row contains more icons than fit on screen, scroll horizontally. The panel supports keyboard focus and arrow-key navigation; Escape dismisses an open panel.

## Other settings

- **Show the second row when the pointer enters the menu bar** enables hover reveal.
- **Open at login** starts OverflowBar in the background.
- Turn off **Hide selected icons** to reveal the selected items.
- Select **Cancel** to stop an active layout operation.
- Choose **More → Reset Icon Selection** and confirm to clear the selection and restore icons.
- Quit OverflowBar to reveal managed icons while keeping saved choices.

## If something does not work

Items that cannot be identified or verified stay accessible. On macOS 27 and later the v1.5 engine leaves icons in the menu bar. Review [Troubleshooting](TROUBLESHOOTING.md) and [Permissions](PERMISSIONS.md) for recovery steps.
